👋 欢迎使用大肥鱼助手

1. 在主窗口登录 DeepSeek 账号；2. 按需修改下方快捷键；3. 回到主窗口，按下快捷键即可截图并自动粘贴到输入框，手动按回车发送。

全局快捷键

点击输入框后按下新的按键组合即可修改（单键如 F1、组合键如 Ctrl+Alt+D），保存后立即生效，无需重启。

启动与窗口

浏览器数据

清除 DeepSeek 网页的 Cookie / 缓存 / 本地数据。清理后需要重新登录 DeepSeek。

桌面悬浮窗（鲸鱼娘）

支持 PNG / JPG / GIF / WEBP 动图

关于

大肥鱼助手：全局快捷键截图 → 写入剪贴板 → 自动粘贴到 DeepSeek 输入框 → 手动按回车发送。截图只在本地处理，不上传任何第三方服务器（DeepSeek 网页除外）。

  • 粘贴失效？点击输入框后手动 Ctrl+V；或按 README 安装并重编译 robotjs。
  • 截图黑屏？以环境变量 DSH_DISABLE_GPU=1 启动应用。
  • 快捷键冲突？换一个组合键即可，保存时会自动检测。
